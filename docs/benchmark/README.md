# Synthetic benchmark snapshot

Generated with `_Example/reproducible_inversion.py`, using its defaults:
four independent seeds, 1,000 states per chain, 250-state burn-in and 3% noise.
The metadata records exact settings, dependency versions and source hashes.
The figure is a workflow demonstration, not a converged velocity recovery.

Run the example to generate the complete NPZ/JSON/PNG/SVG record. The large
chain arrays are not committed here. The arrays can be inspected without pickle;
see [the reproducibility guide](../REPRODUCIBLE_RUNS.md). UTC timestamps and
platform/version fields will naturally change between environments.
