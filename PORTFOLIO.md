# Research software portfolio

## Mohammad-Amin Aminian

**Geophysicist · Scientific software developer · Seismic signal processing**

My work focuses on extracting quantitative information from geophysical signals, with an emphasis on **ocean-bottom seismology**, **seafloor compliance**, **spectral analysis**, **instrument calibration**, **inverse problems**, and reproducible scientific computing.

My doctoral research at the **Institut de Physique du Globe de Paris (IPGP), Université Paris Cité** developed and applied seafloor-compliance methods to broadband ocean-bottom data from the RHUM-RUM experiment in the Indian Ocean.

## Selected research software

### [ComPy](https://github.com/MohammadAmin-Aminian/ComPy)
Seafloor-compliance processing, differential pressure gauge calibration, spectral quality control and layered elastic inversion for broadband ocean-bottom observations.

### [OBS Transient Cleaner](https://github.com/MohammadAmin-Aminian/obs-transient-cleaner)
Detection and removal of repeating instrumental transients in ocean-bottom seismic records, with timing-preserving chunked processing and quantitative synthetic validation.

### [ComPy Inversion Tuner](https://github.com/MohammadAmin-Aminian/compy-inversion-tuner)
Optuna-based tuning of proposal scales and regularization controls for the ComPy compliance inversion workflow.

### [RHUM-RUM Geospatial Mapper](https://github.com/MohammadAmin-Aminian/rhum-rum-geospatial-mapper)
Reproducible PyGMT/GMT mapping of OBS stations, bathymetry, ridge geometry and tectonic context for the RHUM-RUM experiment.

### [VRE Seismic Enhancement](https://github.com/MohammadAmin-Aminian/vre-seismic-enhancement)
Python implementation of Virtual Resolution Enhancement for seismic sections, with numerical comparison to the original MATLAB workflow.

### [Gabor Seismic Filter](https://github.com/MohammadAmin-Aminian/gabor-seismic-filter)
MATLAB Gabor filter-bank workflow for orientation-selective processing of 2-D seismic sections.

## Methods and tools

**Scientific computing:** Python, NumPy, SciPy, ObsPy, Pandas, Matplotlib, PyGMT, disba  
**Inverse problems:** Metropolis-Hastings MCMC, regularization, Optuna, layered elastic modelling  
**Signal processing:** Welch PSD, coherence, transfer functions, spectral ratios, time-frequency analysis, transient removal  
**Geophysics:** ocean-bottom seismology, passive seismic data, seafloor compliance, shear-velocity structure, seismic reflection processing  
**Software practice:** pytest, GitHub Actions, reproducible examples, command-line tools, package metadata, citation metadata
